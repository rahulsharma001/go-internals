# Week 01 practice — Go recovery

Create one directory per task ID, for example `G01-slices/`.

1. Save the untouched first submission as `attempt-01-raw/` and commit it before fixes.
2. Put reviewed corrections in `attempt-02-fix/`; never overwrite the raw attempt.
3. Include a runnable `main()` unless the drill explicitly uses tests as its executable surface.
4. Record the timer, hints, expected/actual output, explanation, complexity, edge cases, modification, and later rewrite in a local `ATTEMPT.md`.
5. Ask Codex to run `gofmt -d`, `go test ./...`, and `go vet ./...`; add `go test -race ./...` for G12 or any concurrent variant.
