# Java DSA Practice Conflicts with Go Interviews

## Observed failure

DSA practice was performed in Java while interviewing for Go roles, so pattern recognition did not reliably transfer to Go syntax, standard-library use, and complete execution.

## Correction policy

All new NeetCode attempts use Go. Historical Java knowledge may inform the approach but never counts as a Go completion. Track syntax, pattern selection, edge cases, complexity, communication, and modification failures separately.

## Smallest correction drill

Re-attempt Contains Duplicate, Two Sum, and Valid Anagram in Go from blank files. Each program must run normal and edge cases from `main()` or a complete table test. Modify one constraint after the initial solution.
